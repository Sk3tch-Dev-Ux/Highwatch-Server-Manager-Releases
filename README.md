# HIGHWATCH SERVER MANAGER

Host DayZ servers on your own Windows PC. A setup guide takes you from an empty PC to a server your friends can join: a background service that keeps it running with the window closed, DayZ Server and Workshop mods downloaded with your Steam account, the Windows firewall and your router set up, a check from the internet that players can reach you, and Highwatch watching over it all.

This repository holds release builds only. The Server Manager is in early access and needs a Highwatch access key to run.

## Download

Get the newest build from **[Releases](https://github.com/Sk3tch-Dev-Ux/Highwatch-Server-Manager-Releases/releases/latest)**.

- **Windows 10 or 11 (64-bit):** `Highwatch-Server-Manager-Setup-<version>.exe`. The installer is not signed yet, so SmartScreen warns. Choose More info, then Run anyway.

You also need a Steam account that owns DayZ and the Steam Mobile App to sign in with a QR code. Highwatch never sees your Steam password.

## Early access

On first launch the Server Manager asks for your access key. Ask for one in our Discord: https://discord.gg/9ug8Yv4kg8

While it runs, the Server Manager reports to us every five minutes so we can see that it works and help when it does not: your key label, app and system versions, and the names, maps and states of your servers. Never credentials, file paths, IP addresses or anything about your players.

The Server Manager updates itself. A new build downloads in the background and asks for one restart.
